BarberBookingBot — асинхронный Telegram-бот для автоматизации записи клиентов в барбершоп / салон красоты.

Ключевой функционал:

    📅 Динамическая сетка записи с фильтрацией занятых слотов времени в реальном времени.

    🔔 Двусторонняя система уведомлений (клиент ↔ администратор) с обработкой статусов (pending, confirmed, rejected).

    ⏰ Автоматические фоновые напоминания клиентам перед визитом (APScheduler).

    📋 Управление записями: просмотр активных броней и отмена в 1 клик.

    📍 Информационный блок (контакты, геопозиция, режим работы).


Стек технологий:

    Python 3.12

    aiogram 3.x (FSM, Router, Inline/Reply Keyboards)

    aiosqlite (Async SQLite)

    APScheduler (AsyncIOScheduler)
